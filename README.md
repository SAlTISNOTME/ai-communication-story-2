# What Influences AI Acceptance in Corporate Communications?

什么因素在影响企业中的AI接受度？——交互式双语研究叙事网站

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000 即可预览（默认中文，右上角可切换 EN）。

## 结构

- 技术栈：Next.js 14 + React 18 + framer-motion + Tailwind（沿用参考站的呈现与交互体系）
- 交互区块：
  1. 封面 Hero（滚动缩放淡出、标题分行动画）
  2. 因素场（13 个可拖动方块）
  3. 研究方法
  4. 访谈对象弹幕（19 位专家浮动，颜色区分群体、符号区分性别）
  5. 研究问题 RQ1 / RQ2
  6. 变革潜力（三个领域卡片 + 原话引用）
  7. 微观层面因素（手风琴展开引用）
  8. 中观层面因素（组织认知 / 组织框架 两组）
  9. 互动拖拽题：把「企业传播」徽章向上或向右拖 = 提升答对，向下/向左提示再想想
  10. 受访者共识 + 为什么
  11. 结语：AI 不会取代人类

文案数据集中在 `data/story.ts`，文案修改只需要改这一个文件。
